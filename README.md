# Mini Motus & Pendu - TP JavaScript

Un projet pedagogique pour faire creer un mini-jeu en JavaScript a des eleves debutants, apres un premier TP sur les bases du langage.

Le parcours principal est un **Mini Motus**. Une variante **Pendu** est fournie pour les eleves qui preferent un jeu plus classique ou plus simple a terminer.

## Fichiers du projet

| Fichier | Description |
|---|---|
| `tp-stagiaires.html` | TP interactif guide avec iterations, editeur de code, validation et sauvegarde locale. |
| `index.html` | Version finale du Mini Motus. |
| `style.css` | Styles de la version finale. |
| `script.js` | Logique complete du Mini Motus. |
| `student/motus.html` | Version eleve Motus a completer, deployable sur Netlify Drop. |
| `student/pendu.html` | Variante eleve Pendu a completer, deployable sur Netlify Drop. |
| `student/student-style.css` | Styles communs aux versions eleves. |

## Objectifs pedagogiques

- Reutiliser les bases vues en JavaScript.
- Manipuler des variables, tableaux, conditions et boucles.
- Lire une valeur saisie par l'utilisateur.
- Modifier le DOM avec `textContent`, `className` et `createElement`.
- Gerer un compteur d'essais.
- Terminer par un vrai mini-jeu publie sur Netlify.

## Deroule conseille

1. Ouvrir `tp-stagiaires.html`.
2. Faire les iterations communes.
3. Choisir une voie:
   - Mini Motus pour un challenge plus visuel.
   - Pendu pour une variante plus progressive.
4. Completer un fichier dans `student/`.
5. Tester dans le navigateur.
6. Deployer sur Netlify Drop.

## Deploiement Netlify

Les fichiers du dossier `student/` sont autonomes.

1. Ouvrir [app.netlify.com/drop](https://app.netlify.com/drop).
2. Glisser le fichier `student/motus.html` ou `student/pendu.html`.
3. Recuperer l'URL publique.
